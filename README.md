# TP1 - Fundamentos de Desenvolvimento com C#

Exercícios do TP1 da disciplina de Fundamentos de Desenvolvimento com C#.

## Exercícios

- Exercício 1: Informações do ambiente e sistema operacional
- Exercício 2: Explicação sobre compilação e CLR
- Exercício 3: Arquivos gerados no build
- Exercício 4: Cálculo de tarifa do estacionamento
- Exercício 5: Classificação de permanência
- Exercício 6: Loop com sentinela (-1) e relatório do turno
- Exercício 7: Menu interativo com métodos
- Exercício 8: Versão final do menu (EstaCentro)

## Como rodar

Para rodar qualquer um dos exercícios pelo terminal:

```bash
dotnet run --project Exercicio8/MenuEstacionamento
```
